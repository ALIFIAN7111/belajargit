# Belajar Git & GitHub

Repositori ini dibuat sebagai tempat untuk berlatih menggunakan **Git** dan **GitHub**, mulai dari inisialisasi repositori, *commit*, *branching*, hingga menangani *merge conflict*.

## 🛠️ Daftar Materi / Aktivitas
Berikut adalah beberapa hal yang dipelajari atau dicoba di dalam repositori ini:
- [x] Inisialisasi Git (`git init`)
- [x] Melakukan *commit* pertama (`git add` & `git commit`)
- [x] Mengubungkan repositori lokal ke GitHub (`git remote add origin`)
- [ ] Simulasi *Branching* dan *Merging*
- [ ] Penyelesaian *Merge Conflict*
